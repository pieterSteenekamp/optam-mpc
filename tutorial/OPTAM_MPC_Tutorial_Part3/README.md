# OPTAM-MPC Tutorial Part 3

This package supplements the frozen **OPTAM-MPC Nonlinear Starter v0.2.0**.
It teaches an APC engineer to rebuild the familiar 2×2 heat exchanger using
explicit nonlinear equations.

Start with `OPTAM_MPC_Tutorial_Part3_Draft_1.docx` or its PDF rendering.

The `exercise_workspace` contains:

- `00_blank_templates`: untouched generic starter templates.
- `90_completed_reference`: the completed example, archived verified results,
  and fresh verification evidence produced for this tutorial.
- `engineering_record.md`: a worksheet for predictions, independent
  calculations, failures, metrics and conclusions.

The frozen starter package and its user manual remain authoritative. Do not
edit the starter runtime or controller core while completing the tutorial.
